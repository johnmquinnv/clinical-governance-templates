# Medical assistance and evacuation governance

**Maintainer:** John Quinn, MD, MPH, PhD, EMT-P  
**Version:** 0.1.0 · **Updated:** 22 October 2026  
**Status:** original educational demonstration; not approved operational policy. No real patient or employer data.

A generic review framework for documenting responsibilities and assurance. This is not a dispatch algorithm, transport authorisation, equipment prescription or substitute for case-specific clinical assessment.

## Review worksheet

| Area | Questions to document | Evidence / owner / review date |
|---|---|---|
| Scope | What service is proposed, and what lies outside its scope? | |
| Clinical responsibility | Who assesses suitability and who holds clinical responsibility during each phase? | |
| Escalation | What triggers senior review and what happens when the usual contact is unavailable? | |
| Provider assurance | How are qualifications, scope, current competence, indemnity and relevant approvals checked? | |
| Resources | Who confirms the case-specific team, equipment, medicines and logistical requirements? | |
| Consent and information | Who verifies consent, lawful sharing, secure communication and minimum necessary information? | |
| Acceptance and handover | Who confirms receiving acceptance and transfer of responsibility? | |
| Disruption | What is the agreed response to delay, cancellation or changed circumstances? | |
| Review | How are incidents, feedback and improvement actions reviewed? | |

## Generic workflow

Request received → accountable coordinator assigned → relevant clinical and operational review → unresolved requirements escalated → authorised plan documented → acceptance and handover confirmed → review and improvement actions recorded.

Each arrow is a handover of work requiring explicit ownership. Approval criteria must come from the applicable clinical, organisational and legal framework, not this example.

## Synthetic example

A training exercise finds that a receiving contact is recorded but their acceptance is not. The improvement action is to add a structured acceptance field and an owner for unresolved acceptance. The audit measure is the proportion of applicable fictional records with documented acceptance, using a defined denominator. It does not measure clinical transport safety.
